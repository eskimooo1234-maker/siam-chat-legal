SIAM CHAT เป็นแอปพลิเคชันสำหรับค้นพบและแชร์สถานที่ในประเทศไทย เราให้ความสำคัญกับความเป็นส่วนตัวของคุณและมุ่งมั่นปกป้องข้อมูลส่วนบุคคลของคุณตามนโยบายฉบับนี้

§1 ข้อมูลที่เราเก็บรวบรวม

เราเก็บรวบรวมข้อมูลต่อไปนี้เมื่อคุณใช้งาน SIAM CHAT:

  • ข้อมูลบัญชี: อีเมล ชื่อผู้ใช้ และรูปโปรไฟล์ที่คุณกรอกเมื่อสมัครสมาชิก
  • ข้อมูลตำแหน่งที่ตั้ง: พิกัด GPS ที่คุณอนุญาตเพื่อแสดงสถานที่ใกล้เคียง เราขอสิทธิ์เฉพาะตอนที่แอปทำงานอยู่เบื้องหน้า (foreground location only)
  • เนื้อหาที่คุณสร้าง: ชื่อสถานที่ พิกัด ประเภท รีวิว คะแนน และรูปภาพที่คุณเพิ่มลงในแอป
  • ข้อมูลการใช้งาน: ประวัติการเช็คอิน คะแนนสะสม และกิจกรรมในแอป
  • ข้อมูลอุปกรณ์: ประเภทอุปกรณ์และเวอร์ชันระบบปฏิบัติการ (สำหรับการแก้ไขข้อบกพร่อง)

§2 วิธีที่เราใช้ข้อมูลของคุณ

ข้อมูลที่เราเก็บรวบรวมถูกใช้เพื่อ:

  • ให้บริการและปรับปรุงฟีเจอร์ของ SIAM CHAT
  • แสดงสถานที่ใกล้เคียงตามตำแหน่งที่ตั้งของคุณ
  • บันทึกและแสดงเนื้อหาที่คุณสร้าง เช่น หมุดและรีวิว
  • คำนวณและแสดงคะแนนสะสมและสถิติการใช้งาน
  • แก้ไขปัญหาทางเทคนิคและปรับปรุงประสิทธิภาพของแอป

เราไม่ใช้ข้อมูลของคุณเพื่อโฆษณาส่วนบุคคล หรือขายข้อมูลให้บุคคลภายนอก

§3 การแชร์ข้อมูลกับบุคคลที่สาม

เราไม่ขาย ให้เช่า หรือเปิดเผยข้อมูลส่วนบุคคลของคุณแก่บุคคลที่สามเพื่อวัตถุประสงค์ทางการตลาด ข้อมูลของคุณอาจถูกเปิดเผยเฉพาะในกรณีต่อไปนี้:

  • ผู้ให้บริการโครงสร้างพื้นฐาน: ข้อมูลถูกประมวลผลผ่าน Supabase (ฐานข้อมูลและการยืนยันตัวตน) ซึ่งดำเนินการในมาตรฐาน SOC 2 Type II
  • ตามข้อกำหนดทางกฎหมาย: หากมีคำสั่งศาลหรือหน่วยงานของรัฐที่มีอำนาจตามกฎหมาย
  • เนื้อหาสาธารณะ: ชื่อสถานที่และรีวิวที่คุณเพิ่มจะปรากฏต่อผู้ใช้คนอื่นในแอป

§4 บริการของบุคคลที่สาม

SIAM CHAT ใช้บริการของบุคคลที่สามดังต่อไปนี้:

  • Google Places API: สำหรับค้นหาและแสดงข้อมูลสถานที่จาก Google ข้อมูลที่ดึงมาจาก Google อยู่ภายใต้ นโยบายความเป็นส่วนตัวของ Google
  • Supabase: สำหรับการจัดเก็บข้อมูล การยืนยันตัวตน และฟังก์ชันแบ็กเอนด์ อยู่ภายใต้ นโยบายความเป็นส่วนตัวของ Supabase
  • Expo / React Native: แพลตฟอร์มสำหรับพัฒนาแอป ไม่มีการเก็บข้อมูลส่วนบุคคลเพิ่มเติม

§5 การเก็บรักษาข้อมูล

เราเก็บข้อมูลของคุณตราบเท่าที่บัญชีของคุณยังใช้งานอยู่ หรือตามที่จำเป็นในการให้บริการ เมื่อคุณลบบัญชี เราจะลบหรือทำให้ข้อมูลที่สามารถระบุตัวตนได้เป็นนิรนาม ภายใน 30 วัน ยกเว้นข้อมูลที่จำเป็นต้องเก็บตามข้อกำหนดทางกฎหมาย

§6 ความปลอดภัยของข้อมูล

เราใช้มาตรการรักษาความปลอดภัยดังต่อไปนี้:

  • การเข้ารหัส HTTPS สำหรับการส่งข้อมูลทั้งหมด
  • Row Level Security (RLS) บนฐานข้อมูล — ผู้ใช้เข้าถึงได้เฉพาะข้อมูลของตนเอง
  • การยืนยันตัวตนผ่าน JWT tokens ที่มีอายุจำกัด
  • ไม่มีการจัดเก็บรหัสผ่านในรูปแบบที่อ่านได้

อย่างไรก็ตาม ไม่มีระบบใดที่ปลอดภัย 100% หากคุณพบพฤติกรรมที่น่าสงสัย กรุณาติดต่อเราทันที

§7 สิทธิ์ของผู้ใช้

คุณมีสิทธิ์ดังต่อไปนี้เกี่ยวกับข้อมูลของคุณ:

  • เข้าถึง: ขอดูข้อมูลที่เราเก็บเกี่ยวกับคุณ
  • แก้ไข: อัปเดตหรือแก้ไขข้อมูลโปรไฟล์ของคุณได้ในแอป
  • ลบ: ลบสถานที่ รีวิว หรือบัญชีของคุณได้
  • ถอนความยินยอม: ปฏิเสธสิทธิ์ตำแหน่งที่ตั้งได้ในการตั้งค่าอุปกรณ์ (แอปยังคงใช้งานได้บางส่วน)

หากต้องการใช้สิทธิ์เหล่านี้ กรุณาติดต่อเราตามช่องทางในหัวข้อถัดไป
