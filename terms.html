§1 การยอมรับข้อกำหนด

โดยการดาวน์โหลดหรือใช้งาน SIAM CHAT ("แอป") คุณยอมรับข้อกำหนดการใช้งานฉบับนี้ ("ข้อกำหนด") ระหว่างคุณและ Siam Chat Dev ("เรา") หากคุณไม่ยอมรับข้อกำหนดเหล่านี้ กรุณาหยุดใช้งานแอปทันที

เราขอสงวนสิทธิ์ในการปรับปรุงข้อกำหนดเหล่านี้ได้ตลอดเวลา การใช้งานแอปต่อเนื่องหลังจากการเปลี่ยนแปลงถือเป็นการยอมรับข้อกำหนดที่อัปเดต

§2 คำอธิบายบริการ

SIAM CHAT เป็นแอปพลิเคชันที่ให้ผู้ใช้:

  • ค้นพบสถานที่น่าสนใจในประเทศไทย
  • เพิ่มและแชร์สถานที่ใหม่กับชุมชน
  • เขียนรีวิวและให้คะแนนสถานที่
  • สะสมคะแนนจากการมีส่วนร่วมในชุมชน
  • ค้นหาสถานที่ใกล้เคียงด้วย GPS

แอปอาจแสดงข้อมูลจาก Google Places API ซึ่งเป็นข้อมูลจากบุคคลที่สาม เราไม่รับประกันความถูกต้องของข้อมูลดังกล่าว

§3 บัญชีผู้ใช้

เพื่อใช้งานฟีเจอร์บางส่วนของแอป คุณต้องสร้างบัญชีผู้ใช้ คุณรับผิดชอบต่อ:

  • ความถูกต้องของข้อมูลที่ให้ไว้ในการลงทะเบียน
  • การรักษาความลับของรหัสผ่าน
  • กิจกรรมทั้งหมดที่เกิดขึ้นภายใต้บัญชีของคุณ

คุณต้องมีอายุอย่างน้อย 13 ปี หรืออายุขั้นต่ำที่กฎหมายในประเทศของคุณกำหนดสำหรับการใช้บริการดิจิทัล

§4 เนื้อหาที่ผู้ใช้สร้าง

เมื่อคุณเพิ่มสถานที่ รีวิว หรือเนื้อหาอื่น ๆ ลงในแอป:

  • คุณยังคงเป็นเจ้าของเนื้อหาของคุณ
  • คุณให้สิทธิ์เราในการแสดง เก็บ และแชร์เนื้อหาดังกล่าวในแอปกับผู้ใช้คนอื่น
  • คุณรับรองว่าเนื้อหาที่คุณเพิ่มเป็นข้อมูลที่ถูกต้องและไม่ละเมิดสิทธิ์ของผู้อื่น
  • คุณสามารถลบเนื้อหาของคุณได้ตลอดเวลาผ่านแอป

§5 พฤติกรรมที่ต้องห้าม

ห้ามใช้แอปเพื่อ:

  • เพิ่มข้อมูลสถานที่ที่เป็นเท็จหรือทำให้เข้าใจผิด
  • ละเมิดสิทธิ์ความเป็นส่วนตัวของบุคคลอื่น
  • แชร์เนื้อหาที่ผิดกฎหมาย ลามก หรือเป็นการคุกคาม
  • พยายามเข้าถึงระบบหรือข้อมูลโดยไม่ได้รับอนุญาต
  • ฟาร์มคะแนนด้วยการสร้างและลบสถานที่ซ้ำ ๆ
  • ใช้บอทหรือโปรแกรมอัตโนมัติในการโต้ตอบกับแอป

เราขอสงวนสิทธิ์ในการระงับหรือยกเลิกบัญชีที่ละเมิดข้อกำหนดเหล่านี้

§6 ทรัพย์สินทางปัญญา

แอป SIAM CHAT รวมถึงโค้ด การออกแบบ และเนื้อหาที่เราสร้างขึ้น เป็นทรัพย์สินของ Siam Chat Dev และได้รับความคุ้มครองตามกฎหมายทรัพย์สินทางปัญญา

ข้อมูลสถานที่ที่ดึงมาจาก Google Places API อยู่ภายใต้ข้อกำหนดการใช้งานของ Google Maps Platform

§7 ข้อจำกัดความรับผิด

แอป SIAM CHAT ให้บริการ "ตามสภาพที่เป็น" (as-is) โดยไม่มีการรับประกันใด ๆ ทั้งโดยชัดแจ้งหรือโดยนัย

ในขอบเขตสูงสุดที่กฎหมายอนุญาต เราจะไม่รับผิดชอบต่อ:

  • ความไม่ถูกต้องของข้อมูลสถานที่จากแหล่งบุคคลที่สาม
  • การสูญหายของข้อมูลหรือการหยุดชะงักของบริการ
  • ความเสียหายทางอ้อมหรือพิเศษที่เกิดจากการใช้งานแอป

§8 การยุติบริการ

คุณสามารถยุติการใช้งานได้ทุกเมื่อโดยลบแอปออกจากอุปกรณ์ หากต้องการลบบัญชีและข้อมูลทั้งหมด กรุณาติดต่อเราตามช่องทางในหัวข้อ §9

เราขอสงวนสิทธิ์ในการระงับหรือยุติการให้บริการแก่บัญชีที่ละเมิดข้อกำหนดนี้ หรือหยุดให้บริการแอปทั้งหมดโดยแจ้งให้ทราบล่วงหน้าเท่าที่เป็นไปได้
